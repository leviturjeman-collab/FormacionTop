# Troubleshooting y errores reales

Esta carpeta entrena diagnostico. Una formacion profesional de IA no puede limitarse a enseñar caminos felices. Los proyectos reales fallan: claves API mal configuradas, permisos insuficientes, JSON roto, webhooks duplicados, modelos lentos, agentes que llaman tools incorrectas, workflows que reciben datos incompletos y codigo que rompe tests. El alumno debe aprender a mirar evidencia.

## Metodo de diagnostico

1. Reproducir.
2. Identificar entrada.
3. Revisar salida.
4. Leer logs.
5. Comparar contra caso correcto.
6. Cambiar una cosa.
7. Verificar.
8. Documentar causa y prevencion.

La frase clave: no se adivina, se observa.
