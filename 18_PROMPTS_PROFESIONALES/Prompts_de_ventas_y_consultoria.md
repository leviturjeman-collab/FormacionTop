# Prompts de ventas y consultoria

Estos prompts ayudan a convertir capacidades tecnicas en conversaciones comerciales responsables. No deben usarse para prometer resultados falsos, sino para aclarar problemas, alcance y valor.

## Discovery

```text
Actua como consultor de IA. Ayudame a preparar preguntas para descubrir oportunidades de automatizacion en [tipo de negocio]. Separa preguntas por: captacion, operaciones, soporte, contenido, reporting, ventas y riesgos. Incluye señales de que NO conviene automatizar todavia.
```

## Propuesta

```text
Con esta informacion del cliente: [datos], crea una propuesta clara. Incluye problema, objetivo, alcance, fuera de alcance, fases, entregables, responsabilidades del cliente, riesgos, precio orientativo por rangos y siguiente paso. No prometas resultados no verificables.
```

## Caso de estudio

```text
Convierte este proyecto en caso de estudio. Estructura: contexto, problema, solucion, arquitectura, herramientas, antes/despues, resultados medibles, limites, aprendizajes y siguiente mejora.
```

## Practica

El alumno debe preparar una propuesta para un caso ficticio. BREAK: cliente pide automatizar un proceso que no entiende. FIX: vender primero auditoria o mapeo de proceso.
