# Prompts de investigacion

Los prompts de investigacion sirven para recopilar, organizar y evaluar informacion. Deben usarse con fuentes, fechas y criterio. No se aceptan afirmaciones importantes sin origen.

## Prompt base

```text
Quiero investigar [tema] para [objetivo]. Usa solo fuentes oficiales o primarias cuando sea posible. Devuelveme:
1. resumen ejecutivo,
2. conceptos clave,
3. tabla de fuentes con enlace, fecha y autoridad,
4. contradicciones o dudas,
5. implicaciones practicas,
6. ideas para clase o proyecto.
No inventes datos. Si algo no esta claro, dilo.
```

## Prompt de comparativa

```text
Compara [herramienta A], [herramienta B] y [herramienta C] para [caso de uso]. Evalua: coste, facilidad, privacidad, integraciones, curva de aprendizaje, riesgos, mantenimiento y nivel recomendado. Termina con una recomendacion por perfil: principiante, intermedio y avanzado.
```

## Prompt de fuente critica

```text
Analiza esta fuente: [pegar texto o enlace]. Separa hechos, claims, supuestos y recomendaciones. Indica que partes requieren verificacion externa y que partes se pueden usar en una formacion.
```

## Practica

El alumno debe investigar una herramienta oficial y crear una nota de Obsidian. BREAK: usar una fuente comercial no oficial como si fuera documentacion. FIX: marcarla como secundaria y buscar fuente primaria.
