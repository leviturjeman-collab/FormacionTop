# Biblioteca de prompts profesionales

Esta carpeta contiene prompts reutilizables, pero no como frases magicas. Cada prompt debe verse como una herramienta de trabajo con objetivo, contexto, formato, restricciones y criterio de revision. Un prompt profesional no busca una respuesta bonita; busca un resultado util, verificable y adaptable.

## Estructura de prompt recomendada

```text
Objetivo:
Contexto:
Material disponible:
Restricciones:
Formato de salida:
Criterio de calidad:
Que no debes hacer:
Preguntas antes de responder si falta algo:
```

La biblioteca debe crecer con ejemplos reales del alumno. Cada prompt usado en un proyecto debe guardarse junto al resultado y una nota de revision: que funciono, que fallo y como mejorarlo.
