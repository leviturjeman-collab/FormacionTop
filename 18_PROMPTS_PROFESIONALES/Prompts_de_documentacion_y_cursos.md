# Prompts de documentacion y cursos

Estos prompts ayudan a convertir conocimiento en material formativo. Deben respetar el metodo de la academia: explicar, practicar, romper, reparar y evaluar.

## Prompt de presentacion

```text
Convierte esta nota en una presentacion de [numero] diapositivas. Cada diapositiva debe tener titulo, mensaje central, bullets cortos, ejemplo y nota del ponente. Mantén una progresion clara: problema, concepto, ejemplo, practica, error, solucion y cierre.
```

## Prompt de rubrica

```text
Crea una rubrica para evaluar [competencia]. Usa niveles: insuficiente, basico, intermedio, avanzado y de máximo nivel. Evalua claridad, ejecucion, diagnostico, seguridad, documentacion y defensa oral.
```

## Practica

El alumno toma cualquier archivo de la boveda y lo convierte en clase. BREAK: generar una clase sin ejercicios. FIX: anadir laboratorio con CHECK, DO, BREAK, FIX y EXPLAIN.
