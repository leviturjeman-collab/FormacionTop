# Herramientas del itinerario

Cada una de estas herramientas tiene **20 lecciones**, con los mismos huecos y
el mismo nivel de detalle. Ver [[Estructura_de_las_20_lecciones]].

## Bloque 1 · Hablar con la IA

| Herramienta | Para qué entra en el curso |
|---|---|
| ChatGPT | La puerta de entrada. Todo el mundo empieza aquí |
| Claude | Textos largos, documentos y trabajo con criterio |
| Gemini | Lo que ya está dentro de Google: Drive, Gmail, Sheets |

## Bloque 2 · Construir sin saber programar

| Herramienta | Para qué entra en el curso |
|---|---|
| Lovable | De una frase a una web funcionando, sin tocar código |
| v0 | Pantallas y componentes a partir de una descripción |
| Claude Code | Cuando el proyecto ya no cabe en una caja de chat |
| Cursor | El editor donde la IA vive dentro del código |
| GitHub Copilot | El acompañante mientras escribes |

## Bloque 3 · Automatizar procesos

| Herramienta | Para qué entra en el curso |
|---|---|
| n8n | Automatizaciones serias, con lógica y alojadas por ti |
| Zapier y Make | Conectar aplicaciones sin instalar nada |

## Bloque 4 · Crear imagen, vídeo y voz

| Herramienta | Para qué entra en el curso |
|---|---|
| Higgsfield | Vídeo con IA: planos, movimiento de cámara y anuncios |
| ElevenLabs | Voz y doblaje que no suena a robot |

| Runway | Edición y efectos de vídeo con IA |

## Bloque 5 · La base que sostiene todo

| Herramienta | Para qué entra en el curso |

## Total

19 herramientas x 20 lecciones = **380 lecciones**.

## Qué pasa con lo que ya había

Las lecciones que existen hoy no se tiran: se reparten por estos huecos y se
reescriben al estándar. Lo que no encaja en ningún hueco se queda en la
biblioteca como material de consulta, no como lección del itinerario.
