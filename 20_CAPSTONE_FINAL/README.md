# Capstone final - Sistema completo de IA

Esta carpeta contiene el proyecto final de la academia. El capstone demuestra que el alumno puede integrar investigacion, prompts, automatizacion, agentes, documentacion, evaluacion, seguridad y presentacion.

## Resultado esperado

El alumno debe construir un sistema real o simulado que resuelva un problema concreto. No tiene que usar todas las herramientas, pero debe justificar las que usa y las que descarta. Un capstone excelente podria combinar Obsidian, ChatGPT/Codex, Claude/Cursor, n8n, Gemini, Ollama o Hermes, pero solo cuando tenga sentido.
