# Proyecto final - Sistema completo de IA

El proyecto final consiste en construir un sistema de IA aplicado a un problema real. Debe tener usuario, entrada, proceso, salida, revision humana, documentacion y evaluacion.

## Fase 1 - Eleccion del problema

El alumno elige un problema de su profesion: soporte, propuestas, investigacion, contenido, reporting, operaciones o codigo. Debe escribir por que importa, quien lo sufre y que seria una mejora medible.

## Fase 2 - Arquitectura

Define herramientas. Ejemplo: Obsidian para documentacion, ChatGPT para estructurar, n8n para orquestar, Gemini para extraccion, Cursor para app, Ollama para procesamiento local y humano para aprobacion. No se premia usar muchas herramientas; se premia elegir bien.

## Fase 3 - Construccion

Crear artefactos: prompts, workflow, documentos, schema, repositorio, base de conocimiento, plantilla o demo. Cada artefacto debe tener criterio de terminado.

## Fase 4 - Error provocado

El alumno debe romper su sistema: dato faltante, JSON invalido, fuente mala, tool incorrecta, webhook duplicado, modelo local lento o permiso insuficiente.

## Fase 5 - Reparacion

Documenta causa, evidencia, cambio y prevencion. Esta fase vale mucho porque demuestra criterio.

## Fase 6 - Entrega

Entrega README, demo, arquitectura, manual de uso, pruebas, riesgos, costes y siguiente mejora.

## Ejemplos de capstone

- Asistente de soporte para negocio local.
- Motor de propuestas para consultor.
- Pipeline editorial para creador.
- Workflow de operaciones internas.
- Revisor de codigo con rules y checklist.
- Sistema RAG privado con Ollama.
