# Plan semanal para alumnos

Este archivo sirve para convertir cualquier fase en una semana clara de trabajo. La estructura recomendada es siempre la misma: estudiar, practicar, romper, reparar, documentar y compartir.

## Lunes - Estudio

Leer una nota principal y resumirla en 10 bullets. El alumno debe marcar terminos que no entiende y buscar en el glosario. Salida: nota breve.

## Martes - Practica

Ejecutar un laboratorio pequeño. No importa que sea perfecto. Importa que el alumno toque la herramienta y observe entradas/salidas.

## Miercoles - Error provocado

Romper algo de forma controlada: prompt ambiguo, JSON invalido, API key mal, webhook duplicado, test fallando o fuente desactualizada.

## Jueves - Reparacion

Documentar causa, sintoma, evidencia, cambio y prevencion. Esta es la parte donde se forma criterio profesional.

## Viernes - Entregable

Crear una pieza: documento, workflow, prompt, plantilla, presentacion, mini demo o caso de estudio.

## Fin de semana - Reflexion

Responder: que aprendi, que puedo aplicar a mi trabajo, que me bloqueo, que repetiria y que proyecto podria crear con esto.
