# Casos por profesion

Esta carpeta traduce la formacion tecnica a contextos profesionales reales. Es una pieza clave porque muchos alumnos no compran ni aprenden "herramientas"; compran transformacion aplicada a su trabajo. Una persona no quiere saber n8n por saber n8n. Quiere ahorrar horas, captar clientes, responder mejor, documentar procesos, crear contenido, analizar datos, vender servicios o construir productos. Por eso esta carpeta reorganiza la academia desde la pregunta que de verdad importa: "yo, con mi trabajo, que puedo hacer con todo esto?".

La regla de esta carpeta es que cada profesion debe tener tres capas: oportunidades, sistemas y entregables. Las oportunidades responden a que problemas se pueden resolver. Los sistemas explican como se conectan herramientas como ChatGPT, Claude, Gemini, Codex, Cursor, n8n, Ollama o Hermes. Los entregables convierten la teoria en algo que el alumno puede mostrar: una auditoria, una automatizacion, un asistente, una presentacion, una base de conocimiento, un workflow, una plantilla, un panel o un caso de estudio.

## Como usar esta carpeta

Primero, el alumno identifica su contexto. Si no tiene una profesion clara, elige el caso que mas se parece a su realidad. Despues lee el archivo correspondiente y marca tres problemas repetitivos de su trabajo. Luego convierte uno en proyecto pequeno. La secuencia recomendada es: problema, datos, herramienta, flujo, salida, revision humana y medicion.

Ejemplo: una agencia no empieza creando "un agente IA". Empieza detectando que pierde tiempo redactando propuestas. El sistema podria ser: formulario de discovery, resumen con ChatGPT o Claude, plantilla de propuesta, n8n para crear documento, revision humana y envio. Si el sistema funciona, se convierte en servicio interno o producto para clientes.
