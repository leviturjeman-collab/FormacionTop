# Freelancers y consultores

Para freelancers y consultores, la IA tiene valor cuando aumenta capacidad sin destruir criterio. El problema tipico no es falta de ideas, sino exceso de tareas pequeÃ±as: captar clientes, preparar propuestas, investigar sectores, documentar reuniones, crear entregables, responder correos, organizar conocimiento, generar contenido y hacer seguimiento. Esta ruta ensena a convertir la IA en un sistema de operacion personal.

## Basico

El nivel basico empieza con ChatGPT o Claude para estructurar trabajo. El freelancer debe crear prompts para discovery de cliente, resumen de reuniones, propuesta inicial, checklist de entrega y plan semanal. No necesita todavia agentes autonomos. Necesita claridad. Una practica ideal es tomar una reunion simulada y convertirla en brief, lista de dudas, alcance, riesgos y proxima accion.

## Intermedio

En intermedio entra n8n. El consultor puede automatizar formularios de entrada, crear carpetas, generar documentos, enviar confirmaciones, registrar leads y hacer seguimiento. Tambien puede usar Gemini o OpenAI para extraer campos de respuestas largas y Cursor/Codex si crea herramientas internas. La clave es no automatizar la relacion humana; se automatiza la administracion que rodea la relacion.

## Avanzado

En avanzado, el freelancer crea un sistema completo: CRM simple, generador de propuestas, base de conocimiento, seguimiento de oportunidades, biblioteca de entregables y dashboard de estado. Puede usar Ollama si maneja datos sensibles y necesita procesarlos localmente. Puede usar Hermes si quiere un asistente persistente que recuerde estilo, clientes y procesos, siempre con politica de memoria.

## Proyecto recomendado

Construir un "motor de propuestas". Entrada: formulario de cliente. Proceso: clasificacion del proyecto, preguntas faltantes, estructura de propuesta, estimacion por rangos, riesgos, entregables y calendario. Salida: propuesta revisable. BREAK: cliente ambiguo, presupuesto inexistente, sector desconocido. FIX: marcar supuestos, pedir aclaraciones y no inventar alcance.

## Entregables

- Plantilla de discovery.
- Prompt de propuesta.
- Workflow de seguimiento.
- Checklist de entrega.
- Caso de estudio antes/despues.
- Rubrica de calidad de propuesta.

## Que evitar

Evitar prometer resultados sin informacion, delegar decisiones comerciales sensibles, enviar propuestas automaticas sin revision o usar modelos con datos privados sin consentimiento. El consultor profesional usa IA para preparar mejor su criterio, no para ocultar ausencia de criterio.
